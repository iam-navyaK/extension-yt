# YouTube Timestamp Bookmark Extension

A Chrome extension that allows you to bookmark specific timestamps in YouTube videos, making it easy to revisit them later. You can add, edit, and delete bookmarks, assign tags, export them, and even share your bookmarks with friends!

## Features

- **Bookmark Timestamps**: Save specific timestamps in YouTube videos.
- **Tagging System**: Assign tags to your bookmarks for better organization.
- **Edit Timestamps**: Modify the details and tags of your saved bookmarks.
- **Delete Timestamps**: Remove any unwanted timestamps.
- **Export Bookmarks**: Export all saved bookmarks as a `.json` or `.csv` file.

- **Keyboard Shortcuts**: Quickly add a bookmark using the shortcut `Ctrl + Shift + B` (or `Command + Shift + B` on macOS).

## Installation

1. **Clone the repository**:

   ```bash
   git clone https://github.com/iam-navyaK/bookmark-extension-yt.git
````

2. **Navigate to the project directory**:

   ```bash
   cd bookmark-extension-yt
   ```

3. **Load the extension in Chrome**:

   * Open Chrome and go to `chrome://extensions/`
   * Enable **Developer Mode** (toggle in the top-right corner).
   * Click **Load Unpacked** and select the folder where the extension files are located.

4. **Permissions**:

   * The extension will request permission to interact with YouTube and store bookmarks locally in your browser.

## Usage

1. **Bookmarking**:

   * Navigate to a YouTube video.
   * Click the extension icon in the toolbar or use the keyboard shortcut `Ctrl + Shift + B` (or `Command + Shift + B` on macOS) to bookmark the current timestamp.

2. **Tags**:

   * Add tags (e.g., `#tutorial`, `#music`) to your saved timestamps to help you organize your bookmarks.

3. **View and Edit Bookmarks**:

   * Click the extension icon to view and edit your saved bookmarks in the popup window.

4. **Export Bookmarks**:

   * Click the **Export** button to export your bookmarks as a `.json` or `.csv` file.


### Keyboard Shortcuts

* **`Ctrl + Shift + B`** (Windows/Linux) or **`Command + Shift + B`** (macOS):

  * Add a new bookmark to the current timestamp on YouTube.
