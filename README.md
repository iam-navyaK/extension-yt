YouTube Timestamp Bookmark Extension
A Chrome extension that allows you to bookmark specific timestamps in YouTube videos and revisit them easily. You can add, edit, and delete timestamps, assign tags, and share your bookmarks with others!

Features
Bookmark Timestamps: Capture and save specific timestamps in YouTube videos.

Tagging System: Add tags to your bookmarks for better organization.

Edit Timestamps: Modify timestamp details and tags.

Delete Timestamps: Remove unwanted bookmarks.

Export Bookmarks: Export your bookmarks with timestamps and tags to a file.

Keyboard Shortcuts: Quickly add a bookmark with Ctrl + Shift + B (or Command + Shift + B on macOS).

Load the Extension in Chrome:

Go to chrome://extensions/ in your Chrome browser.

Enable Developer Mode (top-right).

Click Load Unpacked and select the extension folder.

Set up permissions:

This extension requires permission to interact with YouTube and store your bookmarks locally.

Usage
Once installed, you’ll see the extension icon in the Chrome toolbar.

Navigate to any YouTube video and click the extension icon or use the keyboard shortcut (Ctrl + Shift + B or Command + Shift + B on macOS) to save the timestamp.

Add tags to your bookmarks to categorize them (e.g., #tutorial, #music).

View, edit, delete, and export your saved timestamps in the extension’s popup.

Keyboard Shortcuts
Ctrl + Shift + B (Windows/Linux) or Command + Shift + B (macOS): Add a new bookmark.


How to Export Bookmarks
You can export your saved bookmarks (including timestamps and tags) to a .json or .csv file for backup or sharing.
